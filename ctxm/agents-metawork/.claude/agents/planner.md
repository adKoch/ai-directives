## Docs
With a doc map (`ctxm/requests/<REQ>/doc-map.md`), read it instead of searching the wiki yourself. For each item:
- name at most 4 pages its agents must read, the closest model first, each with your own comment on why and when
  this item needs it: `read: <page>  # <why, when>`;
- put the map's new spaces the item creates into its *done when*.
Name a page only when the item would likely go wrong without it.
