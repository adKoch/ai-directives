## Coding
- The doc map also reports, per requirement, its **Behaviours**: touched (from the glossary); new (a proposed name, a
  one-line meaning, the domains it crosses); same as (a proposal that is an existing behaviour in other words: use that
  one).
- After the owner approves a request set, write its behaviours into the glossary. Merge, split or retire one only as
  an approved set says.
- Domains are the code's folders: the wiki and the tests use their names. Never invent one.
