## Coding
Also read for:
- a function with more than one purpose or an effect its name does not predict; mixed levels of detail; flag
  parameters; a command that also answers;
- effects inside logic; dependencies pointing outward; test or demo code in product code;
- LLM habits: re-introduced variables, wrappers that only rename, comments that repeat the code, abstractions with one
  use, a second way beside an existing pattern;
- test tampering (blocking unless the item requires it): removed tests or assertions, skip markers, changed expected
  values or fixtures, wider tolerances or timeouts, smaller test sizes, test-mode branches in product code;
- a test without a `catches:` line naming an existing behaviour, defect or rule.
