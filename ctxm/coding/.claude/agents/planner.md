## Coding
- Plan by domain; split an item whose work crosses domains along them.
- Each item names the behaviours it touches, from the doc map.
- A shared script, manifest or lock file belongs to one item at a time.
- An item that would repeat a manual command starts by adding its script.
- An area whose probes need a helper tool the project lacks gets a foundation item that builds it first.
- Trivial, so the inspector may be skipped: text, and data values without logic.
